# OpenAnima

[![CI](https://github.com/losadgm/OpenAnima/actions/workflows/ci.yml/badge.svg)](https://github.com/losadgm/OpenAnima/actions/workflows/ci.yml)
[![C++17](https://img.shields.io/badge/C%2B%2B-17-blue.svg)](https://github.com/losadgm/OpenAnima)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://github.com/losadgm/OpenAnima/blob/main/LICENSE)

C++17 middleware for a world of agents: NPCs that talk to the player, sources that log what
happens around them, and senses that decide what each NPC makes of it.

- Documentation: https://losadgm.github.io/OpenAnima/
- API reference: https://losadgm.github.io/OpenAnima/api/
- Roadmap: https://losadgm.github.io/OpenAnima/roadmap.html
